# Project description
Данное приложение - это домашние задание по темам: Junit & Mockito тестированию и работы с базой данных через JDBC. В проекте также используется H2 база данных в режиме in mem. Основные классы в проекте это: класс репозитория DbRepository, для работы с базой данных, класс сервиса Service для обработки и выдачи результатов запросов. Сборка проекта осуществляется Maven.

***
# Technologies
1. Maven.
2. H2.
